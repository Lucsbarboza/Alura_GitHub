# Jogo do Número Secreto

Jogo desenvolvido em HTML, CSS e JavaScript durante o curso de lógica de programação da Alura.

## Como funciona

- O computador sorteia um número secreto.
- O jogador digita um chute e recebe uma dica: o número secreto é maior ou menor.
- Ao acertar, o jogo mostra quantas tentativas foram necessárias.
- O botão "Novo jogo" só é liberado após o acerto e reinicia a partida.
- Os números já sorteados não se repetem até que todos tenham saído.

## Conceitos praticados

- Variáveis e funções
- Condicionais (`if/else` e operador ternário)
- Listas (arrays)
- Manipulação do HTML com `document.querySelector`
- Eventos de clique com `onclick`
